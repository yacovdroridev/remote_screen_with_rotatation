# Release v2.2.1

Per-server settings persistence and a full connection editor UI.

---

## What's New in v2.2.1

* **Per-Server Settings Persistence**: Quality, FPS, scale mode, and rotation are now saved per connection profile and automatically restored when you select a saved connection. Changes made during a session (rotation, scale, quality, FPS) are written back to the profile on disconnect.
* **Manage Saved Connections**: A new "Manage Saved Connections" button on the portal opens a glass-panel editor. Each saved profile can be edited inline (target, display, rotation, scale mode, quality, FPS, key path) or deleted. Editing a connection target/display key automatically removes the old record to avoid duplicates.
* **scale_mode in Profile**: Scale mode (`fit` / `fill` / `1:1`) is now included in the `/connect` POST body and saved to `~/.remote_viewer_history.json`.

---

## v2.1.0 — SSH Reconnection & Silent View-Only

* **Automatic SSH Reconnection**: Retries every 5 seconds for up to 90 seconds on unexpected disconnect.
* **Silent pyautogui Absence**: View-only mode entered silently without a UI banner.

---

## v2.0.0 — Go Backend Rewrite

A full rewrite of the server in Go replacing the Python backend.

### Key Features

* **Go Native Backend**: Zero-dependency single binary. No Python, no pip, no venv — just run `remote-viewer`.
* **Native WebView Window**: Uses `webkit2gtk` on Linux and launches Edge/Chrome in `--app=` mode on Windows for a clean borderless desktop app experience.
* **AnyDesk-style P2P Session Approval**: Share your screen with associates without giving them SSH credentials. Guests request access; a modal slides onto the host screen for 1-click Approve / Deny.
* **Embedded Tailscale Mesh VPN Panel**: Auto-detection, 1-click background daemon install, and OAuth login flow for zero-config mesh networking.
* **Robust Multi-Auth**: Passwords, custom key files, default key scan (`~/.ssh/id_rsa`, `id_ed25519`, etc.), and SSH agent forwarding.
* **Saved Connection Profiles**: MRU-ordered chips in the portal for 1-click reconnect. Passwords are never persisted to disk.
* **Zero-CPU Rotations**: `0°`, `90°`, `180°`, `270°` handled entirely in the local canvas — 0% remote CPU.
* **Figma-Style Panning in 1:1 Mode**: Spacebar-drag and middle-click drag for panning high-res screens. Ctrl+scroll zoom.
